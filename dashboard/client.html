Method

How this platform actually works — no marketing gloss.

The engine

Every strategy is backtested on a tick-by-tick simulation engine — over 207 million real recorded XAUUSD ticks, not resampled minute bars. Stops, take-profits, slippage, swap and latency are evaluated on every single tick, the same way a broker would fill them.

The engine is deterministic: the same data and settings always produce the same result, bit for bit. Results are reproducible and auditable.

Risk & compliance gates

  • Every order passes the same pipeline — sizing, risk limits, compliance rules and mode approval. No signal can bypass the gates, in backtest or live.
  • Fail closed — if a rule set isn't verified, if the kill switch is engaged, or if account data is missing, orders are refused. The platform never guesses.
  • Honest data labels — delayed, synthetic and stale feeds are labelled as exactly what they are. Nothing recorded is ever presented as live.
  • Kill switch — a human can block all new entries instantly, and every action is written to an audit log.

What this portal shows

The charts use real recorded market data, replayed with a delay. The performance numbers come from the same deterministic engine that runs the research pipeline — same fills, same costs, same rules.

Past performance of a backtest is not indicative of future results. Live execution stays locked until explicit human sign-off.
